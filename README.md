<summary><b><code>▸ projects</code></b> &nbsp;<sub>things I've built</sub></summary>
<br>

> Most of these live in private client repos — the interactive terminal has the full breakdown.

**`ZipMart`** &nbsp;·&nbsp; <sub>quick-commerce · TypeScript</sub>
Instant grocery delivery. A React Native + Expo monorepo shipping **three apps from one codebase** — customer, delivery partner, and store owner — with live order state and partner assignment.

**`Swavritti`** &nbsp;·&nbsp; <sub>marketplace · TypeScript</sub>
स्ववृत्ति — a free, open-source, **non-profit** freelance marketplace. Zero commission by design, AI-assisted fair pricing, optional escrow, and the freedom to work and get paid off-platform.

**`PreSchool Management SaaS`** &nbsp;·&nbsp; <sub>saas · Dart + Node</sub>
Multi-tenant platform running many schools off one backend, with role-scoped access for admin, staff, and parents — plus a Flutter app for academics and attendance.

**`Makhana Health King`** &nbsp;·&nbsp; <sub>e-commerce · TypeScript + Node</sub>
Full commerce stack across three repos: storefront, merchant admin, and the API behind both.

**`Lead Agent`** &nbsp;·&nbsp; <sub>saas · automation</sub>
Sources and enriches leads, then runs email and WhatsApp outreach unattended.

**`UltraCoreWood`** &nbsp;·&nbsp; <sub>e-commerce · JavaScript</sub>
Furniture commerce — catalog-heavy storefront, operations admin, backend, and a React Native companion app.
